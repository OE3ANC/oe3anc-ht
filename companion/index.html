Disconnect the live companion first. Use your established C62 manual bootloader/reset procedure with the programming cable, then connect here. Release physical PTT before serial communication; it shares the RX pin. Automatic DTR/RTS reset is not enabled. This connection loads a helper into RAM and does not erase or write flash.

These tools work independently of the application firmware version. Keep the radio powered and the cable connected until the operation finishes. Dump and retain a complete backup before updating. Cancelled or failed reads do not produce a successful backup. Unplug before rebooting into normal operation.
