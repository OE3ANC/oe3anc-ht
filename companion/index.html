Cable and bootloader notes

Physical PTT shares the serial RX pin. Automatic DTR/RTS reset is not enabled. Connecting loads a helper into RAM without changing flash. These tools work independently of the installed application version.

Keep power and cable connected until each operation completes. Unplug before rebooting into normal operation.

Factory calibration

Read the factory power-calibration tables without changing them. PWM duty percentages are not measured RF watts.

Table inspection verifies the 64 KiB journal at 0x3B0000–0x3C0000. The raw download separately reads and verifies the entire factory region to the end of flash.
